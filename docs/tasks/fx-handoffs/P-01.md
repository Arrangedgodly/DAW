## Actual Chrome run

Run in Chrome `154.0.0.0` on Windows 10/11 x64, foreground tab, `http://127.0.0.1:5194/audio-engine-benchmark.html`.

- Context: 44.1 kHz; browser-reported `baseLatency` 10.00 ms and `outputLatency` 0.00 ms (metadata only).
- Workload: deterministic 8.0 s stereo program, 53,802-frame / 1.220000 s seeded stereo IR (`0x5eed`, size 0.65), mix 0.5, 512-frame blocks, 407,040 output frames including tail, five timed passes after one warm-up.
- Elementary prime: 1,024 silent frames; asserted silent. Dry impulses at 0, 512, and 1,024 each emerged at their exact index with amplitude 1.0; left/right dry isolation passed.
- Dry wire: exactly equal over all 407,040 frames and both channels.
- Fixed wet: relative RMS displayed 0.0000%; peak `2.794e-9` at left sample 154,886. First nonzero index was sample 0 in both engines/channels. Startup, settled, and tail relative RMS each displayed 0.0000%.
- Fixed full chain: relative RMS displayed 0.0000%; peak `5.960e-8` at right sample 22,050; startup/settled/tail relative RMS each displayed 0.0000%.
- L-only IR impulse: relative RMS displayed 0.0000%, peak `1.630e-9` at left sample 4,863, opposite-channel peak 0 in both renderers. R-only: relative RMS displayed 0.0000%, peak `1.863e-9` at right sample 1,066, opposite-channel peak 0 in both renderers. Assertions passed.
- Actual production startup first 100 ms: RMS `0.01426114`, peak `0.80098909` at left sample 0. Reported separately from fixed-gain parity.
- Settled timing used 4,096 silent pre-roll frames (92.88 ms), followed by the same signal and complete tail: 411,136 frames in both engines. Native `createReverbDevice` raw `startRendering` ms: `197.80, 151.40, 134.80, 132.50, 126.20`; median `134.80 ms`, `69.16x` real time. Elementary fixed graph raw `process` ms: `105.30, 120.20, 98.30, 98.70, 101.50`; median `101.50 ms`, `91.85x` real time. Final settled output relative RMS displayed 0.0001%.
- This is offline throughput, not DSP CPU load, render deadline success, physical latency, or an engine recommendation. Timers include asynchronous native `startRendering` vs synchronous Elementary processing and its JS/WASM block copies; both exclude graph setup, IR generation, allocation, and channel extraction. The native/Elementary reported percentage is not an engine-selection conclusion.
