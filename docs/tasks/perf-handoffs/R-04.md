## Scope, decision, and verification

This PR adds only `tests/perf/mixer-graph.mjs`, its raw JSON, this handoff, and `docs/dev/mixer-graph-profile.md`. It does not edit the production audio path, schemas, scheduler horizon, FX host, spectrum path, other probes, or the manager ledger. The diagnostic stripped graph lives only in the browser harness. The eight-lane default construction median of 5.35 ms gives no basis for a safe lazy-node implementation: the achievable slice is smaller than removing the whole production graph, live render cost remains unobserved, and enabling nodes later has graph-state/click/lifecycle risk. No-change is the conclusion for this PR. A later implementation requires attributable live deadline/glitch evidence, a repeated app Play setup target, preserved sound/graph transitions, offline parity, and lifecycle checks.
