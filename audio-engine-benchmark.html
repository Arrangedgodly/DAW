Reverb engine comparison

This development-only tool runs fixed-gain parity probes separately from Bitbounce’s production reverb startup and settled offline throughput. It uses a deterministic stereo input and seeded impulse response. It does not play audio or change a project.

Run it in the target browser and device with other heavy work closed. It warms both renderers, checks dry impulse alignment and stereo routing, reports full-tail differences, then alternates five sequential timed passes.

Ready. The run takes a few seconds and does not play sound.
